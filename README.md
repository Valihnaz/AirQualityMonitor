# Air Quality Monitor (ESP32)

Simple air quality monitoring system using ESP32, DHT22, and MQ2 sensor.

## Features
- Temperature and humidity monitoring
- Gas concentration (MQ2)
- Automatic control (fan, heater, humidifier)
- Blynk integration
- Data history tracking

## Tech stack
- ESP32 (Arduino framework)
- Blynk
- DHT22 + MQ2 sensors

## How to run
1. Open project in PlatformIO / Wokwi
2. Set your Blynk credentials in secret.h.example
3. Build and upload
